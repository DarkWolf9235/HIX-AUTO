# HIX-AUTO

Website for **Hix Auto Worx**, a mobile mechanic serving Jacksonville, NC and surrounding areas.

Static frontend only (HTML/CSS/JS), no build step and no backend. Deployed on Vercel.

## Structure

```
index.html        page markup
styles.css        all styles (black / red / white brand)
script.js         mobile menu + scroll reveal
assets/img/       logos cut from the business poster, job photos, favicon
```

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
